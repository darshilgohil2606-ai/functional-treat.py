# Data Analyzer and Transformer Program

## 1. Introduction
The Data Analyzer and Transformer Program is a menu-driven Python application that allows users to input, analyze, filter, and sort numerical data. It also provides a factorial calculation feature and displays useful statistical information about the dataset.

## 2. Objectives
- To understand Python lists and data handling.
- To perform basic mathematical calculations.
- To learn functions and recursion in Python.
- To filter and sort numerical data.
- To create a menu-driven program using conditional statements and loops.

## 3. Features
1. **Input Data:** Accepts integer values separated by spaces and stores them in a list.
2. **Display Data Summary:** Displays the total number of elements, minimum value, maximum value, sum, and average.
3. **Calculate Factorial:** Calculates the factorial of a given number using recursion.
4. **Filter Data by Threshold:** Displays values greater than the specified threshold.
5. **Sort Data:** Sorts the data in ascending or descending order.
6. **Display Dataset Statistics:** Calculates and displays the maximum, minimum, sum, and average values.
7. **Exit Program:** Terminates the program with a goodbye message.

## 4. Technologies Used
- **Programming Language:** Python
- **Concepts Used:** Lists, loops, conditional statements, functions, recursion, lambda functions, filter(), and sorting.

## 5. Requirements
- Python 3.x installed on the computer.
- Any Python code editor, such as IDLE, VS Code, or PyCharm.

## 6. How to Run the Program
1. Install Python 3.x on your computer.
2. Open a Python editor.
3. Copy the program code and save it as `data_analyzer.py`.
4. Run the file.
5. Select an option from the main menu.
6. Enter the required data or numbers when prompted.
7. Select option 7 to exit the program.

## 8. Advantages
- Easy to use because of its menu-driven interface.
- Performs calculations quickly.
- Helps users understand basic data analysis.
- Demonstrates several important Python programming concepts.

## 9. Limitations
- The program works with integer data only.
- The dataset must be entered before selecting options that analyze it.
- Invalid text input may cause an error.
- Negative numbers are not valid inputs for the factorial calculation.

## 10. Conclusion
The Data Analyzer and Transformer Program is a simple Python project that demonstrates how to store, analyze, filter, and sort numerical data. It also helps develop an understanding of functions, recursion, loops, and basic statistical calculations. This project is useful for beginners who want to improve their Python programming skills.
